Les bureaux de Paris, Gouda et Parme sont équipés de copieurs multifonctions **Ricoh IM C3000**. Toutes les impressions passent par l'impression sécurisée : le document attend sur le serveur tant que vous ne vous êtes pas identifié sur le copieur.

## Libérer une impression

1. Envoyez le document vers la file **Fromage-Secure** (elle est installée d'office sur les postes du siège).
2. Au copieur, passez votre badge sur le lecteur à droite de l'écran.
3. Choisissez **Impressions en attente**, cochez vos documents, puis **Imprimer**.

Les documents non libérés sont supprimés au bout de 24 heures.

## Mon document n'apparaît pas au copieur

- Vérifiez dans la barre des tâches que le travail est bien parti vers **Fromage-Secure** et non vers une ancienne imprimante locale.
- Si la file Windows affiche « Erreur » ou reste bloquée sur « Mise en file d'attente », ouvrez **Paramètres > Imprimantes**, sélectionnez Fromage-Secure, puis **Ouvrir la file d'attente > Annuler tous les documents**, et relancez l'impression.
- Votre badge doit être enregistré : la première fois, le copieur demande votre identifiant et votre mot de passe Windows pour l'associer.

## Ajouter le copieur sur un poste

Depuis le **Centre logiciel**, installez le paquet « Impression sécurisée Ricoh ». Aucun pilote n'est à télécharger sur le site du fabricant.

## Papier, toner, bourrage

Le papier et le toner sont gérés par les services généraux ; un bourrage sur un copieur Ricoh se résout en suivant l'animation affichée à l'écran. Les imprimantes d'étiquettes des entrepôts ne sont pas des Ricoh : elles ont leur propre procédure.
